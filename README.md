# WareFlow 360 — Warehouse Management Service

A static web-based business app prototype created for the ITBT Live Class Exercise.

## Business
**WareFlow 360 — Smart Warehouse Management & Control Tower**

## Business Problem
Customers and warehouse managers may lack clear visibility into inventory and order movement. This prototype addresses that problem through a centralized warehouse dashboard.

## Main Features
- Home section
- About Business section
- Warehouse services and sample pricing
- Manager dashboard with 6 KPIs
- Orders Received vs Dispatched chart
- Warehouse utilization visualization
- Interactive Order / SKU Search
- Stock-out watchlist
- Customer enquiry form
- Business-purpose hyperlinks
- Responsive design for desktop and mobile

## GitHub Pages
1. Create a GitHub repository, for example `Abhishek-WareFlow360`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the entire `images` folder.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select the `main` branch and root folder.
5. Save and open the published GitHub Pages URL.

## Important
This is an academic prototype using demo data. The sample prices, KPIs and records are illustrative and are not connected to a live WMS, ERP or database.
